Key parameters for all prompts:
- Use --style raw for Midjourney to reduce default stylization
- Specify --no cartoon, illustration, drawing, sketch (to avoid overly artistic interpretations)
- Add --no glass, glossy, plastic, neon to prevent unwanted material effects
- For web screenshot style: add "website screenshot, browser chrome visible, address bar showing localhost:3000" if needed
- Always include aspect ratio (--ar) appropriate for the use case (16:9 for hero, 3:2 for case studies)
- Version specifier (--v 6.0) for latest model capabilities

Usage notes:
1. These prompts are designed to generate visual references/mockups only - not to replace actual implementation
2. Generated images should be used for stakeholder alignment and visual direction setting
3. Always verify generated content against actual design specifications and accessibility requirements
4. The prompts focus on tangible, visual elements (paper texture, ink colors, tab shapes) rather than abstract concepts
5. Avoid prompts that claim to generate "working code" or "functional website" - stick to visual mockups
