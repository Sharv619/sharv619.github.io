# Technical Field Journal Design System

## Product
Evidence-first portfolio for Himanshu Lade, a Sydney-based Full-Stack Systems and AI Engineer. The UI must preserve automatic GitHub ingestion, static project routes, case studies, resume, and browser-only Repo RAG.

## Visual direction
Authentic premium engineer's field journal with restrained workflow controls. Use a leather-bound notebook shell, aged paper, ruled and graph-paper surfaces, stitched binding, technical diagrams, marginal evidence tabs, verification stamps, and crisp editorial typography. It must feel senior and precise, never whimsical or scrapbook-like.

## Tokens
- Paper: #fdf6e3
- Paper raised: #fffaf0
- Ink: #2b2118
- Leather: #5c4033
- Leather dark: #1a1a1a
- Dark page: #2d2d2d
- Dark ink: #f5deb3
- Rule: #e6d3b3
- Brass: #b98b3d
- Verification: #c41e3a
- Serif headings: IBM Plex Serif
- Body: IBM Plex Sans
- Technical labels: IBM Plex Mono
- Radius: 2px tabs, 6px controls, 10px journal cards
- Shadows: restrained paper lift only

## Layout
Sticky 64px paper navigation inside a leather edge. Homepage hero is a two-page notebook spread: identity and positioning on the left; real portfolio evidence pipeline architecture on the right. Below it, editorial case-study cards and a searchable field index. Use natural scrolling, not mandatory section snap.

## Components
- EvidenceTab: narrow red or brass marginal tab with source kind and external-link affordance.
- JournalCard: crisp paper sheet, thin rule, red margin, subtle 2-4px lift.
- ArchitectureNote: graph-paper panel with semantic boxes/arrows and source links.
- WorkflowControls: compact squared filters and search, not desktop-window chrome.
- Assistant: sticky-note launcher opening a notebook panel with evidence tabs.

## Motion
Subtle tactile motion only: small lifts, tab slides, ink fades, and diagram line reveals. Respect prefers-reduced-motion. No page-turn navigation, fake terminal, typewriter delay, parallax, or glowing AI effects.

## Constraints
No portrait. No purple gradients, glassmorphism, isometric city, OS desktop, Matrix motifs, fake claims, fabricated diagrams, or hardcoded projects. Use actual portfolio and GitHub evidence. Preserve accessibility, static export, SEO, and mobile usability.
